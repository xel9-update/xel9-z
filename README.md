## 설치

- **Windows:** 받은 파일을 실행하고 안내를 따릅니다. 게시자가 "1Pixel Inc."로 표시됩니다.
- **macOS:** 받은 `.dmg`를 열고 XEL9-Z를 **응용 프로그램** 폴더로 끌어다 놓습니다.
- **Linux:** `.deb`나 `.rpm`은 두 번 눌러 설치합니다. AppImage는 실행 권한을 준 뒤 바로 실행합니다.

## 할 수 있는 일

- **압축 풀기:** 압축 파일을 두 번 누르거나 우클릭 메뉴에서 "여기에 풀기"를 고릅니다. zip, 7z, rar, alz, egg, tar, iso를 비롯한 여러 형식을 엽니다.
- **압축하기:** 파일이나 폴더를 zip, 7z 등으로 묶습니다. 비밀번호도 걸 수 있습니다.
- **암호화 보관함:** 파일 내용뿐 아니라 이름·크기·폴더 구조까지 감춥니다. 같은 폴더를 다시 넣으면 바뀐 부분만 저장합니다.
- **위험한 압축 파일 차단:** 엉뚱한 폴더에 파일을 쓰려는 압축 파일이나 압축 폭탄은 풀기 전에 막습니다.
- **내 컴퓨터 안에서만:** 업데이트 확인을 켜지 않으면 인터넷에 연결하지 않습니다.

## English

XEL9-Z is a file compression app for Windows, macOS and Linux. It opens almost any archive you receive (zip, 7z, rar, alz/egg, tar, iso and more) and keeps your sensitive files in an encrypted vault where nobody can see even the file names without the password. No ads, no prompts to pay.

### Install

- **Windows:** run the downloaded file and follow the steps. The publisher is shown as "1Pixel Inc."
- **macOS:** open the `.dmg` and drag XEL9-Z into the **Applications** folder.
- **Linux:** double-click the `.deb` or `.rpm` to install it. The AppImage runs as it is once you make it executable.

### What it does

- **Extract:** double-click an archive, or choose "Extract here" from the right-click menu. It opens zip, 7z, rar, alz, egg, tar, iso and many more.
- **Compress:** pack files or folders into zip, 7z and other formats, with a password if you like.
- **Encrypted vault:** hides file names, sizes and the folder structure, not just the contents. Add the same folder again and only what changed is stored.
- **Stops dangerous archives:** archives that try to write outside the target folder, and zip bombs, are caught before anything is extracted.
- **Stays on your computer:** the app does not connect to the internet unless you turn on update checks.

### Updating

Open **Settings → Updates** in the app to check for a new version and install it. Turn on "Check for updates at startup" to be told when one is out.

To do it by hand, download the latest file from the table above and install it over the existing app. Your settings and vaults stay as they are.
